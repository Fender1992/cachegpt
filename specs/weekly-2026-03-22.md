# Weekly Improvement Spec — 2026-03-22

## Priority: Add API Status Badge to Landing Page

### Goal
Add a small, real-time status indicator to the landing page that shows whether the CacheGPT API is healthy. This gives users confidence the service is running.

### Requirements

1. Create a new component `components/status-badge.tsx`:
   - Fetches `/api/health` on mount
   - Shows a green dot + "Operational" if status is 200
   - Shows a red dot + "Degraded" if status is not 200
   - Auto-refreshes every 60 seconds
   - Small, unobtrusive — sits in the footer or header

2. Add the component to the landing page layout (not the chat page)

3. Style with Tailwind — match existing design system

### Constraints
- No new dependencies
- No protected files modified
- Maximum ~50 lines of new code
- Must include a test file

### Test Plan
- Component renders without crashing
- Shows "Operational" when fetch returns 200
- Shows "Degraded" when fetch fails
- Auto-refresh interval is set
